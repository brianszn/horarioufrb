# Horários (UFRB)

Organizador/visualizador de horários por código (ex: `2M123 4T12`).

## Como usar

- Preencha **Nome da matéria** e o **Código do horário**.
- A grade faz uma prévia do que será ocupado.
- Se houver choque com outra matéria já adicionada, o botão **Adicionar** fica desabilitado e o conflito é marcado.
- As matérias ficam salvas no **cache do navegador** (localStorage).
